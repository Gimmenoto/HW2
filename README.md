## 🛠️ วิธีการรันโปรเจกต์ (How to run)

สามารถรันหน้าเว็บดูได้ง่ายๆ ผ่าน VS Code ตามขั้นตอนด้านล่างนี้เลย:

1. เปิดโฟลเดอร์โปรเจกต์นี้ในโปรแกรม **VS Code**
2. ไปที่แถบ Extensions (หรือกด `Ctrl+Shift+X`) แล้วค้นหาและติดตั้ง Extension ที่ชื่อว่า **Live Server**
3. หลังจากติดตั้งเสร็จ ให้เปิดไฟล์ `index.html` (หรือไฟล์ HTML หลักของโปรเจกต์) ขึ้นมา
4. สังเกตที่แถบด้านล่างขวาของหน้าต่าง VS Code แล้วคลิกที่คำว่า **"Go Live"**
5. เบราว์เซอร์จะเด้งเปิดหน้าเว็บขึ้นมาให้แบบอัตโนมัติเลย

ยกเว้น sql-injection ต้อง
1. npm install
2. node server.js
